本篇教程为 Debian 12 Bookworm 专属，从零部署官方开源 Impostor 服务端，全程稳定无坑、支持开机自启、崩溃重启、后台常驻，适合搭建长期稳定的 AmongUs 公益私人服务器。
一、前期准备
设备要求
- 操作系统：Debian 12 x64
- 最低配置：1核 512M 内存（仅适合 2-6 人游玩）
- 推荐配置：1核 1G 内存以上（10人+稳定不卡顿）
- 网络要求：拥有公网IP，开放端口权限
默认端口
游戏端口：22023 TCP/UDP
二、更新系统与安装基础依赖
首先更新系统并安装必备工具，保证后续部署无依赖缺失：
apt update && apt upgrade -y
apt install wget curl unzip screen ufw nano -y
三、安装 .NET 8 运行环境（必装）
Impostor 服务端基于 .NET8 开发，必须安装对应运行环境才能启动。
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb
dpkg -i packages-microsoft-prod.deb
rm -f packages-microsoft-prod.deb
apt update
apt install aspnetcore-runtime-8.0 -y

# 验证是否安装成功
dotnet --version
输出版本号即为安装成功。
四、防火墙放行端口
放行 SSH 远程连接端口与游戏端口，保证外网可正常联机：
ufw allow 22/tcp
ufw allow 22023
ufw allow 22023/udp
ufw enable
ufw status
重要提醒：国内云服务器（腾讯云/阿里云/华为云）必须在官网安全组手动放行 22023 TCP/UDP，仅服务器防火墙放行无效！
五、下载最新 Impostor 服务端
自动获取官方最新 Release 版本服务端，无需手动找包：
mkdir -p /opt/impostor
cd /opt/impostor
LATEST=$(curl -s https://api.github.com/repos/Impostor/Impostor/releases/latest | grep browser_download_url | grep linux-x64 | cut -d '"' -f 4)
wget $LATEST -O impostor.tar.gz
tar -zxvf impostor.tar.gz
chmod +x ./Impostor.Server
六、服务端核心配置优化
修改 config.json，填入公网IP，开启最佳优化参数：
nano config.json
{
  "PublicIp": "你的服务器公网IP",
  "PublicPort": 22023,
  "ListenIp": "0.0.0.0",
  "ListenPort": 22023,
  "MaxPlayers": 15,
  "ServerName": "MinCiallo 公益私服",
  "EnableHttpApi": true,
  "AllowCheats": false,
  "HideIpAddresses": true,
  "BanIpAfterBan": true
}
保存：Ctrl+O 回车，退出：Ctrl+X
七、配置 Systemd 开机自启（生产稳定方案）
配置系统守护进程，实现开机自启、崩溃自动重启、后台常驻：
nano /etc/systemd/system/impostor.service
[Unit]
Description=Impostor AmongUs Private Server
After=network.target

[Service]
WorkingDirectory=/opt/impostor
ExecStart=/opt/impostor/Impostor.Server
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
加载并启动服务：
systemctl daemon-reload
systemctl enable impostor
systemctl start impostor
systemctl status impostor
显示 active(running) 即为运行成功。
八、服务器日常管理命令大全
systemctl start impostor     # 启动服务器
systemctl stop impostor      # 停止服务器
systemctl restart impostor   # 重启服务器
systemctl status impostor    # 查看运行状态
journalctl -u impostor -f    # 实时查看运行日志
九、玩家客户端完整联机教程
1. 打开官方私服配置工具：https://impostor.github.io/Impostor/
2. 填写你的服务器 IP / 域名 + 端口 22023
3. 点击下载 regionInfo.json
4. 按下 Win + R 输入路径：
%APPDATA%\..\LocalLow\Innersloth\Among Us
5. 替换目录内原有的 regionInfo.json
6. 重启 Among Us，右下角地区切换为你的私服即可联机
十、常见问题 & 踩坑解决
1. 外网无法连接服务器
99% 是云服务器安全组未放行 22023 端口，或 config 填写内网IP。
2. 服务启动瞬间闪退
.NET8 运行环境未安装成功，重新执行环境安装步骤。
3. 房间卡顿、高延迟、掉线
服务器内存过低，建议升级 1G+ 内存，国内服务器延迟最佳。
4. 多人联机报错
适当调高 MaxPlayers，保证端口稳定无占用。
十一、进阶优化建议
1. 使用国内服务器搭建，延迟更低、联机更稳；
2. 定期重启服务，释放内存；
3. 禁止外挂与恶意玩家，保证游玩环境；
4. 可搭配域名解析，使用域名代替IP连接。
