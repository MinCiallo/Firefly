# 本站邮箱已支持收发邮件：Cloudflare + Resend 方案

本站的联系邮箱功能已正式上线，现在可以通过邮件与本站取得联系了。

## 方案概述

本方案分为两个部分：

| 功能 | 服务 | 说明 |
| :--- | :--- | :--- |
| **收件** | Cloudflare Email Routing | 免费，无需服务器，邮件自动转发到个人邮箱 |
| **发件** | Resend | 免费额度（100 封/天），API 方式发送 |

## 收件：Cloudflare Email Routing

### 原理

Cloudflare 的 Email Routing 功能可以把你域名的邮件地址（如 `hello@minciallo.top`）收到的邮件，自动转发到你指定的个人邮箱（如 Gmail、QQ 邮箱等）。

整个过程**不需要任何服务器**，全由 Cloudflare 代劳。

### 配置步骤

1. 进入 [Cloudflare Dashboard](https://dash.cloudflare.com/)，选择你的域名
2. 左侧菜单找到 **Email → Email Routing**
3. 点击 "Get started"，Cloudflare 会自动添加相关的 DNS 记录（MX 记录等）
4. 添加路由规则：
   - **Custom address**：填写你想用的邮箱地址，如 `hello@minciallo.top`
   - **Destination address**：填写你的个人邮箱，如 `minciallo@gmail.com`
5. 保存后，发往 `hello@minciallo.top` 的邮件就会自动转发到你的个人邮箱

### 注意事项

- 收件只能转发，不能像普通邮箱那样直接回复
- 如果需要回复，需要配合发件服务（如 Resend）来实现
- 免费版最多支持 100 个路由规则

## 发件：Resend

### 原理

Resend 是一个邮件发送 API 服务，可以通过 API 调用发送邮件。它提供了免费额度（**100 封/天**），对于个人博客的联系表单来说完全够用。

### 配置步骤

1. 注册 [resend.com](https://resend.com/) 账号
2. 在 **Domains** 中添加你的域名并完成验证
   - Resend 会提供几条 DNS 记录（SPF、DKIM 等），到 Cloudflare DNS 中添加即可
3. 验证通过后，在 **API Keys** 中创建一个 API Key
4. 在你的网站中使用 API 发送邮件

### 发送邮件示例

```javascript
import { Resend } from 'resend';

const resend = new Resend('re_xxxxxxxxxxxx');

await resend.emails.send({
  from: 'hello@minciallo.top',
  to: 'minciallo@gmail.com',
  subject: '来自博客的新消息',
  html: '<p>有人通过博客联系了你！</p>',
});
```

## 为什么选这个组合

| 对比维度 | Cloudflare + Resend | 传统邮箱服务 | 自建邮件服务器 |
| :--- | :--- | :--- | :--- |
| **费用** | 免费 | 免费/付费 | 服务器成本 |
| **维护成本** | 几乎为零 | 低 | 高 |
| **送达率** | 高（Resend 专业发信） | 中 | 低（容易被判垃圾邮件） |
| **配置难度** | 中等 | 简单 | 困难 |

## 小结

Cloudflare Email Routing 负责收件，Resend 负责发件，两者结合就实现了完整的邮箱收发功能，而且完全免费，适合个人博客和小型项目使用。
