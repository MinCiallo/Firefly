# 如何在 Linux 服务器上部署 Terraria 服务器

Terraria 是一款广受欢迎的沙盒冒险游戏，支持多人联机游玩。通过搭建自己的 Terraria 服务器，你可以与好友自由探索、建造和冒险，而无需依赖第三方托管服务。

与游戏自带的“开服并游玩”模式不同，专用服务器（Dedicated Server）可以让你的世界 24/7 全天候在线，即使你关闭游戏，朋友们也能随时进入。Linux 系统以其稳定性、低资源占用和强大的后台管理能力，成为运行 Terraria 服务器的理想选择。

本文将详细介绍如何在 Linux 服务器上从零开始搭建 Terraria 专用服务器。

---

## 前提条件

在开始之前，请确保满足以下条件：

- 一台运行 Linux 的服务器（本文以 **Ubuntu 22.04 LTS** 为例，Debian 12 或其他主流发行版同样适用）
- 服务器的 root 或 sudo 访问权限
- 基本的 Linux 命令行操作经验

### 硬件配置建议

Terraria 服务器对硬件要求很低：

- **内存**：小型私人服务器 1GB 内存即可流畅运行，2GB 更宽裕
- **CPU**：1 核完全够用
- **硬盘**：5GB 空间足够

**提示：** 如果是模组服务器（tModLoader），建议将内存提升至 2–4GB。

---

## 第一步：更新系统并安装依赖

```bash
# Ubuntu / Debian
sudo apt update -y
sudo apt upgrade -y
sudo apt install -y screen unzip wget libgdiplus

# CentOS / RHEL
sudo yum update -y
sudo yum install -y screen unzip wget libgdiplus
````

说明：

* `screen`：后台运行服务器
* `unzip / wget`：下载与解压
* `libgdiplus`：Linux 图形依赖库

---

## 第二步：安装 SteamCMD

```bash
# 创建目录
mkdir -p ~/steamcmd
cd ~/steamcmd

# 下载 SteamCMD
wget https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz
tar -xvzf steamcmd_linux.tar.gz
```

---

## 第三步：下载 Terraria 服务器

```bash
./steamcmd.sh +login anonymous +app_update 105600 validate +quit
```

下载完成后，服务端通常位于：

```bash
~/steamcmd/steamapps/common/Terraria/
```

将其复制到独立目录：

```bash
mkdir -p ~/terraria-server
cp -r ~/steamcmd/steamapps/common/Terraria/* ~/terraria-server/
cd ~/terraria-server
```

---

## 第四步：创建配置文件

```bash
nano ~/terraria-server/serverconfig.txt
```

写入配置：

```ini
world=/home/terraria/terraria-server/Worlds/MyWorld.wld
autocreate=2
worldname=MyWorld
maxplayers=8
port=7777
password=yourpassword
difficulty=0
secure=1
language=en-US
```

---

## 第五步：启动服务器

### 手动启动

```bash
cd ~/terraria-server
chmod +x TerrariaServer*
./TerrariaServer* -config serverconfig.txt
```

> 如果文件名不确定，可以先执行：

```bash
find . -name "TerrariaServer*"
```

---

### 使用 screen 后台运行

```bash
screen -S terraria
cd ~/terraria-server
./TerrariaServer* -config serverconfig.txt
```

分离：

```
Ctrl + A，然后按 D
```

重新进入：

```bash
screen -r terraria
```

---

## 第六步：开放防火墙端口

### Ubuntu / Debian

```bash
sudo ufw allow 7777/tcp
sudo ufw allow 7777/udp
sudo ufw reload
```

### CentOS

```bash
sudo firewall-cmd --permanent --add-port=7777/tcp
sudo firewall-cmd --permanent --add-port=7777/udp
sudo firewall-cmd --reload
```

**注意：**
云服务器还需要在控制台安全组放行 7777 端口（TCP + UDP）。

---

## 第七步：配置 systemd（推荐）

### 创建专用用户（推荐做法）

```bash
sudo useradd -m -s /bin/bash terraria
sudo mkdir -p /home/terraria/terraria-server
sudo chown -R terraria:terraria /home/terraria
```

---

### 创建服务文件

```bash
sudo nano /etc/systemd/system/terraria.service
```

写入：

```ini
[Unit]
Description=Terraria Dedicated Server
After=network.target

[Service]
Type=simple
User=terraria
WorkingDirectory=/home/terraria/terraria-server
ExecStart=/home/terraria/terraria-server/TerrariaServer -config /home/terraria/terraria-server/serverconfig.txt
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

---

### 启动服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable terraria
sudo systemctl start terraria
```

查看状态：

```bash
sudo systemctl status terraria
```

## 连接服务器

1. 打开 Terraria
2. 进入「多人游戏」
3. 选择「通过 IP 加入」
4. 输入服务器 IP + `7777`
5. 输入密码（如果有）

---

## 故障排除

### 无法启动

* 检查 `libgdiplus`
* 检查 serverconfig 路径
* 查看日志：

```bash
journalctl -u terraria -f
```

---

### 无法连接

* 检查 7777 TCP/UDP 是否开放
* 检查云安全组
* 确认服务器已启动（Server started）

---

### 服务器崩溃

* 检查内存是否不足
* 查看 systemd 日志
* 考虑定时重启
