## 如何在 Linux 服务器上部署 Minecraft 服务器

> 发布日期：2026年6月22日 | 标签：`Minecraft` `Linux`

本文详细介绍了如何在 Linux 服务器上从零开始部署 Minecraft Java 版服务器。文章从硬件配置建议（按玩家数量分级）入手，逐步讲解 Java 环境安装、PaperMC 高性能服务端下载与配置、`server.properties` 关键参数调优、防火墙端口开放，以及使用 Screen 或 Systemd 实现进程守护。性能优化部分重点介绍了 Aikar's Flags JVM 参数和 PaperMC 专属优化项，帮助服务器在低配环境下也能流畅运行。

## 如何在 Linux 服务器上部署 Impostor 服务器

> 发布日期：2026年6月23日 | 标签：`Among Us` `Impostor` `Linux`

本文手把手教你如何在 Linux 服务器上搭建 Among Us 私服（Impostor 服务器）。内容涵盖 .NET 运行时安装、Impostor 服务端下载与配置、`config.json` 关键参数（PublicIp、Port、ListenIp）解析、防火墙端口开放、Screen 后台运行，以及针对 Among Us v16.0.5 以上版本强制 HTTPS 连接的反向代理配置方案。文末附带了连接失败、启动失败、被踢出等常见问题的排查指南。

## 如何在 Linux 服务器上部署 Terraria 服务器

> 发布日期：2026年6月24日 | 标签：`Terraria` `Linux`

本文提供了一份完整的 Terraria 专用服务器搭建指南。从 SteamCMD 安装、服务端下载、`serverconfig.txt` 配置文件编写，到 Screen 后台运行和 Systemd 服务配置，步骤清晰完整。Terraria 服务器资源占用极低，1GB 内存即可流畅运行私人服务器，非常适合在低配 VPS 上搭建 24/7 全天候在线的游戏世界。
