## 🖥️ 游戏服务器部署教程

本周连续发布了三篇游戏服务器部署指南，为玩家提供搭建私人服务器的完整方案：

### 如何在 Linux 服务器上部署 Minecraft 服务器（6月22日）

详细介绍了在 Ubuntu Server 上搭建 Minecraft Java 版服务器的完整流程，包括：
- 硬件配置建议（根据玩家数量推荐不同配置）
- Java 环境安装与配置
- PaperMC 服务端下载与配置
- 使用 Screen 和 Systemd 两种方式启动服务器
- JVM 参数调优（Aikar's Flags）
- 常见问题排查

### 如何在 Linux 服务器上部署 Impostor 服务器（6月23日）

手把手教你搭建 Among Us 私服：
- .NET 运行时环境配置
- Impostor 服务端下载与配置
- 防火墙端口开放（UDP/TCP 22023）
- 反向代理配置（支持 HTTPS 协议）
- 客户端连接方法
- 常见问题排查

### 如何在 Linux 服务器上部署 Terraria 服务器（6月24日）

从零开始搭建 24/7 全天候在线的 Terraria 专用服务器：
- SteamCMD 安装与配置
- 服务端下载与配置文件设置
- 手动启动与 Screen 后台运行
- Systemd 服务配置（开机自启）
- 常用服务器命令
- 故障排除指南
